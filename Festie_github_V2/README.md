# Festie V2 — 페스티벌 준비부터 기록까지

ICT융합디자인과 졸업작품 **Festie** 앱 프로토타입 V2입니다.
교수님 피드백을 반영한 버전으로, 처음 실행한 탐색 화면부터 페스티벌을 찾고, 준비하고, 공연 후 리포트를 만드는 과정까지 실제 앱처럼 직접 눌러볼 수 있어요.

## 써보는 순서

1. **탐색**에서 장르 칩이나 검색으로 페스티벌을 찾아요. 검색바를 누르면 검색 화면과 키보드가 바로 열려요.
2. **그랜드 민트 페스티벌 2026** → `준비 시작하기`를 누르면 바로 준비하기 화면으로 가요.
3. 준비하기 4가지를 채워요.
   - **타임테이블**: 1일차를 고르고 담기 → 2일차로 이어가기 (시간이 겹치는 공연은 담을 수 없어요)
   - **플레이리스트**: 고른 공연의 곡이 자동으로 담겨요. 빼고 싶은 곡은 체크를 풀고 음악 앱으로 내보내기
   - **체크리스트**: 챙길 것 모두 체크
   - **티켓**: 권종과 예매처 등록
4. `내 준비 한눈에 보기`에서 입력한 내용을 인포그래픽으로 한 번에 확인해요.
5. 네 가지가 모두 설정 완료되면 **기록** 탭에서 리포트를 만들 수 있어요. 완성한 리포트는 `리포트 수정하기`로 고칠 수 있어요.

새로고침하면 처음 상태로 돌아가요.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 **Public**으로 만들어요 (예: `festie-v2`).
2. 저장소에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일을 **모두** 끌어다 놓아요.
   - `index.html`, `festie-runtime.js`, `morphdom-umd.min.js`, `manifest.webmanifest`, `festie-logo.svg`, 아이콘 3개, `images` 폴더, `.nojekyll`
   - `.nojekyll`처럼 점으로 시작하는 파일이 안 보이면 없어도 동작해요.
3. **Commit changes**를 눌러요.
4. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요.
5. 1~2분 뒤 `https://아이디.github.io/festie-v2/` 주소가 생겨요. (Settings → Pages 맨 위에도 표시돼요)

이미 V1을 올린 저장소가 있다면, 그 저장소에 이 파일들을 덮어써서 올려도 돼요.

## 휴대폰에서 앱처럼 쓰기

- **아이폰**: Safari로 주소를 열고 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 주소를 열고 → 메뉴(⋮) → **홈 화면에 추가**

홈 화면에 festie 로고 아이콘이 생기고, 그 아이콘으로 열면 주소창 없이 전체화면으로 열려요.
V1 아이콘이 이미 홈 화면에 있다면 지우고 다시 추가해야 새 로고로 바뀌어요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 화면과 동작 |
| `festie-runtime.js` | 화면을 그리고 입력에 반응하게 하는 작은 실행 코드 |
| `morphdom-umd.min.js` | 화면을 바꿀 때 스크롤·입력 상태를 지켜주는 라이브러리 (MIT, `morphdom-LICENSE.txt`) |
| `manifest.webmanifest`, `icon-*.png`, `festie-logo.svg` | 홈 화면 아이콘과 브라우저 탭 아이콘 (festie 로고) |
| `images/` | 페스티벌 포스터, 아티스트·현장 사진 |

폰트(Josefin Sans, Hanken Grotesk, Noto Sans KR)는 Google Fonts에서 불러와서, 인터넷이 연결돼 있어야 원래 글꼴로 보여요.
라인업과 곡 목록은 프로토타입용으로 구성한 예시예요.
